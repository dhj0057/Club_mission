# 실패 후 상태 — Java 발표 실행 코드

기존 발표 PPT 1~13장 및 공부 자료와 동일한 예제입니다.
JDK 17 이상이 필요하며 외부 라이브러리는 없습니다.

## 구성
- Main.java: Main(입력·출력), Student(검증·상태 변경), StudentManager(목록 관리), Checks(검증).
- 학습 문서와 맞추기 위해 네 클래스를 한 파일에 담았습니다. public 클래스는 Main입니다.
- run.bat: Windows에서 컴파일 후 메뉴 실행.
- test.bat: Windows에서 컴파일 후 31개 조건 검증.
- VERIFIED_OUTPUT.txt: 제작 환경에서 실제 실행한 검증 출력.

## Windows 실행
1. ZIP을 먼저 모두 압축 해제합니다.
2. failure_state 폴더에서 run.bat을 더블클릭합니다.
3. 검증은 test.bat을 더블클릭합니다.

PowerShell 또는 CMD에서 직접 실행할 수도 있습니다.
```text
javac -version
java -version
chcp 65001
javac -encoding UTF-8 -d out Main.java
java -Dfile.encoding=UTF-8 -cp out Main
```
자동 검증:
```text
java -Dfile.encoding=UTF-8 -cp out Main --test
```
PowerShell에서 배치 파일을 실행하려면 .\run.bat 또는 .\test.bat을 입력합니다.
'javac을 찾을 수 없다'면 JDK 설치 및 PATH 설정을 확인한 뒤 터미널을 다시 엽니다.
한글이 깨지면 Windows Terminal에서 위 명령을 사용하고, 소스 파일은 UTF-8로 유지합니다.

## 발표 시연 순서
| 메뉴 | 입력 | 확인 |
|---|---|---|
| 1 추가 | 민준, 85 | 정상 추가 |
| 4 점수수정 | 번호 1, 점수 150 | 범위 오류 |
| 2 목록 | 없음 | 민준 85점 유지 |
| 4 점수수정 | 번호 1, 점수 100 | 정상 변경 |
| 2 목록 | 없음 | 민준 100점 |
| 4 점수수정 | 번호 1, 점수 abc | 정수 변환 오류 |
| 2 목록 | 없음 | 마지막 정상값 100점 유지 |
| 6 종료 | 없음 | 프로그램 종료 |

## 설명할 핵심
- 검증 전에 대입하면 예외를 잡아도 잘못된 값이 남습니다.
- 검증 후 대입은 범위 검사 실패 시 대입을 실행하지 않아 기존 값을 보존합니다.
- 두 학생을 연속 수정하면 A 성공, B 실패라는 부분 성공이 가능합니다.
- Checks 안의 BadStudent는 의도적으로 잘못된 비교 코드입니다.

## 범위와 확인 상태
- 단일 스레드 콘솔 학습 예제입니다. 파일 저장은 없으며 종료하면 명단이 사라집니다.
- 학생 번호는 현재 목록 위치입니다. 삭제하면 뒤 학생의 번호가 바뀝니다.
- 이름 규칙 검증, 입력 도중 강제 EOF 복구, 동시성·트랜잭션은 구현 범위가 아닙니다.
- List.copyOf는 목록 구조 변경을 제한하지만 Student 자체를 불변으로 만들지는 않습니다.
- 발표 자료 제작 당시의 검증 기록을 동봉했습니다. 이번 포장 작업에서는 Java 실행기 부재로 재실행하지 못했습니다. Windows 배치 파일도 실제 Windows에서 실행 검증하지 않았습니다.
- 자료 제작과 본인의 독립 작성·발표·제출 완료는 별개입니다.
